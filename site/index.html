Narval, a terminal text editor
written in C, configured in Lisp

Language servers, a debugger, git, a package manager and terminal panes, in one small binary with no dependencies. It runs the same on Linux, macOS and Windows, and every setting, key binding and hook is a line of Lisp.

Features

Configured in Lisp

init.lisp is a program: settings, key bindings, hooks and whole packages. Errors are reported with file and line, and the rest still loads.

Language servers (LSP)

Completion, signature help, go to definition, references, diagnostics, outline, workspace symbols, inlay hints, sticky scroll. Offers to install a missing server.

Debugger (DAP)

gdb, lldb-dap, debugpy or any Debug Adapter Protocol server. Breakpoints that follow your edits, conditions, logpoints, watches, inline values.

git built in

Status, hunk staging, commits, push and pull, log and branches, colored diffs, branch and diff markers in the gutter.

Package manager

use-package with versions, dependencies and a lockfile, so the same setup installs on every machine.

Daemon mode

Several terminal windows on one editor: shared buffers and language servers, a project per window.

Terminal panes

Run full-screen programs inside the editor. Plus keyboard macros, mouse support, autosave and crash recovery.

Native everywhere

Plain C99, no dependencies beyond the C library. Windows 10 and 11 run it in Windows Terminal, no WSL needed.

Your editor is a Lisp program

Narval reads ~/.narval/packages/personal-config/init.lisp at start. Define commands, bind keys, react to hooks, declare packages from any git repository. Updates never touch it.

Everything beyond the core is a package written the same way: the C mode, the git UI, the debugger panel. Read them, copy them, change them.

; ~/.narval/packages/personal-config/init.lisp
(define DEBUG-INLINE-VALUES #t)

(map-key "F5" debug-continue "no-prefix")

(lsp-server-install "pyright-langserver" "any"
                    "pipx install pyright")

(use-package "rainbow"
             "https://example.org/rainbow.git" "latest")

(dap-adapter "go" "dlv" "dap"
             "--listen=127.0.0.1:{port}")

Install

macOS and Linux (Homebrew)

brew tap arthur/narval https://git.giorgio-nas.fr/arthur/homebrew-narval.git
brew install narval

Windows (winget)

winget install ArthurBarraux.Narval

Arch Linux (AUR)

yay -S narval-editor

Debian and Ubuntu

sudo curl -fsSL https://git.giorgio-nas.fr/api/packages/arthur/debian/repository.key \
     -o /etc/apt/keyrings/narval.asc
echo "deb [signed-by=/etc/apt/keyrings/narval.asc] https://git.giorgio-nas.fr/api/packages/arthur/debian stable main" \
  | sudo tee /etc/apt/sources.list.d/narval.list
sudo apt update && sudo apt install narval

Fedora, RHEL, openSUSE

sudo curl -fsSL https://git.giorgio-nas.fr/api/packages/arthur/rpm.repo \
     -o /etc/yum.repos.d/narval.repo
sudo dnf install narval

From source

git clone https://git.giorgio-nas.fr/arthur/narval.git
cd narval && ./install.sh

Prebuilt .deb, .rpm and Windows zip files are on the releases page.

First steps

Run narval path/to/file. After a prefix such as Ctrl-x, pause and the keys available under it appear at the bottom of the screen.

Ctrl-x Ctrl-ssave
Ctrl-x Ctrl-cquit
Ctrl-x fopen a file
Ctrl-x h kwhat does this key do?
Ctrl-x c severy setting, with its default
Ctrl-x B cstart the debugger, or continue

Questions

Is Narval the same editor as Beluga?

Yes. Narval was called Beluga up to version 3.5 and was renamed in 4.0. On its first start narval moves ~/.beluga to ~/.narval, and the old BELUGA_* variables and beluga-* Lisp functions keep working.

How does it compare to Emacs, Vim or Neovim?

Like Emacs it is configured in Lisp and uses Ctrl-x style key bindings; like Neovim it speaks LSP and DAP out of the box. Unlike both it is a single small C binary with no runtime to install, and it runs natively on Windows.

Which languages does it support?

Bundled packages cover C and C++ (clangd), Python, Rust, TypeScript and Node.js, Angular, PHP, LaTeX, Markdown, YAML and Lisp. Any other language with a language server is one lsp-server line away, and narval offers to install a missing server.

Is it free?

Yes, Narval is open source under the MIT license.
